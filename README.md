# 모스 스트라이크 (Godot 4.7 이식판)

`MorseStrike/index.html` 프로토타입을 Godot 4.7로 옮긴 버전.
실제 3D(기울어진 카메라, 조명·그림자)로 그리는 2.5D 쿼터뷰 은신 슈터이고, 모델·사운드는 모두 코드로 생성한다(에셋 없음).

## 실행

Godot 4.7로 이 폴더를 열고 실행(F5). 메인 씬은 `scenes/main.tscn`.

- 모바일: 화면 드래그로 이동, 왼쪽 아래 전건 짧게 = 점, 길게 = 선, 옆의 취소 버튼
- PC: WASD 이동, Space 전건, Esc/Backspace 입력 취소, 마우스 클릭·드래그는 터치로 처리됨(`emulate_touch_from_mouse`)
- 기준 해상도 720 x 1280 세로. PC 창은 450 x 800

### 자동 점검

```
godot --path . -- --autotest
```

로비 → 출격 → 지원요청 전부 발사 → 전건을 실제 터치 입력으로 눌러 부호 입력 → 조이스틱 이동 → 1분 시뮬레이션을 돌리고,
`user://autotest_*.png` 스크린샷과 `AUTOTEST ...` 로그를 남긴 뒤 종료한다.

## 좌표

논리는 프로토타입과 같은 2D "게임 단위"(맵 3000 x 3000)로 돌고, 그릴 때만 3D로 옮긴다.

- 위치: `(x, y)` → `Vector3(x * 0.06, 높이, y * 0.06)` (`Game.p3`)
- 각도: 게임 각도 `a` → `rotation.y = -a`. 모든 모델은 +X를 바라보게 만든다
- 엄폐물 높이는 `h * 0.09` m

## 지원요청 연출

- 폭격류(정밀 공습·기총소사·네이팜·융단 폭격)는 실제 폭발 지점마다 실제 피해 반경 원을 그린다(테두리 고정, 안쪽이 시간에 따라 차오름)
- 전투기(융단 폭격은 폭격기)가 공격선 위를 지나가며 폭탄을 떨어뜨리고, 땅에 기체 모양 그림자가 지나간다. 제트 굉음은 `flyby()`에서 합성

## 통신 드론 (진화)

- 조건: 통신 증폭기 Lv3 + 대형 탄두 Lv2 (무기 무관)
- 플레이어 어깨 뒤를 따라다니며 장착한 지원요청을 0.8초마다 판단해 자동 호출한다. 재사용 대기는 플레이어와 따로 돈다(HUD 카드 아래 하늘색 막대)
- 공격형은 교전 중이고 표적이 있을 때만, 보급은 체력 50% 미만, 의무 지원은 교전 중 60% 미만, 방호 장막은 교전 중 35% 미만일 때. 초대형 폭탄은 자동 호출하지 않는다
- 방공포 교란 구역 안에서는 드론도 호출하지 못한다

## 작전 지도

- 지구본은 고정 시드(`WORLD_SEED`)라 매번 같은 세계. 위도로 바이옴이 정해진다: 적도 사막, 중위도 산림, 고위도 설원
- 작전 7곳이 `Save.d.missions`에 저장된다. 성공하면 그 지점은 해방되고 새 지점이 생긴다
- 위험도 정찰/교전/격전: 순찰조 10/14/18개, 경비 -1/0/+1명, 적 체력 x0.85/1.05/1.25, 보상 보너스 0/+50%/+100%

## 게임 규칙 요약

- 주 임무: 단말기 2곳 해킹 → 탈출 SOS(`...---...`) → 30초 버티기 → 헬기 탑승
- 보조 임무: 통신탑(구역·적 위치 공개) / 적 부대(증원 병력 절반) / 방공포(반경 안 지원요청 불가, 파괴 시 재사용 대기 25% 감소)
- 적은 경비병·전초기지·순찰조로 배치된다. 시야(부채꼴)·소음으로 발각되고, 교전에 들어가면 무전병이 증원을 부른다(처치하면 차단)
- 플레이어는 이동 방향을 바라보고, 사거리 안 가장 가까운 적을 자동 조준해 쏜다
- 통신탑 점령을 시작하면 은신 여부와 상관없이 탑 근처에 있는 동안 7초마다 적 증원이 온다(적 부대 파괴 시 절반). 점령 게이지는 구역을 벗어나도 줄지 않는다
- 발각 후 무전 증원은 22명+(증원 횟수x8), 최대 60명이 3파로 몰려온다. 순찰조는 14개조 3~5명
- 무기 진화 시 슬로모션·줌인·충격파 연출, 진화한 무기는 색 궤적·발광 총열·처치 파열 효과
- 부호가 겹치면(짧은 부호가 긴 부호의 앞부분) 0.6초 기다렸다가 짧은 쪽을 발동한다
