# 모스 스트라이크 (Godot 4.7 이식판)

`MorseStrike/index.html` 프로토타입을 Godot 4.7로 옮긴 버전.
실제 3D(기울어진 카메라, 조명·그림자)로 그리는 2.5D 쿼터뷰 은신 슈터이고, 모델·사운드·아이콘은 모두 코드로 생성한다. 외부 에셋은 글꼴(`fonts/`, Pretendard, OFL)뿐이다.

## 실행

Godot 4.7로 이 폴더를 열고 실행(F5). 메인 씬은 `scenes/main.tscn`.

- 모바일: 화면 드래그로 이동, 왼쪽 아래 전건 짧게 = 점, 길게 = 선, 옆의 취소 버튼
- PC: WASD 이동, Space 전건, Esc/Backspace 입력 취소, 마우스 클릭·드래그는 터치로 처리됨(`emulate_touch_from_mouse`)
- 기준 해상도 720 x 1280 세로. PC 창은 450 x 800

### 자동 점검

```
godot --path . -- --autotest
```

로비 → 출격 → 지원요청 전부 발사 → 전건을 실제 터치 입력으로 눌러 부호 입력 → 조이스틱 이동 → 1분 시뮬레이션을 돌리고,
`user://autotest_*.png` 스크린샷과 `AUTOTEST ...` 로그를 남긴 뒤 종료한다.
`AUTOTEST shot` 줄에는 그 순간의 fps와 드로우 콜 수가 같이 찍힌다.

- `--quick`: 로비와 전투 첫 장면만 찍고 끝낸다 (화면 모양만 볼 때)
- `--biome=N`: 0 사막, 1 산림, 2 설원 작전으로 출격한다

## 화면 연출

- 병사는 `actors.gd`의 `BIG`(1.32배)로 키우고 뒤집은 껍질 외곽선을 둘러 바닥과 구분한다. 충돌 판정은 그대로다
- 병사는 몸통·다리 둘·총 = 메시 4개, 전차는 차체·포탑 2개, 건물·나무·바위·차량은 1개다. 전투 화면 드로우 콜이 1,400대에서 400대로 줄었다
- 조명: 따뜻한 햇빛 + 푸른 주변광, 색 보정(대비·채도), 2x MSAA. 엄폐물 밑동에는 접지 그림자 메시를 한 장 깐다(`worldgen._contact`)
- 새 지원요청을 추가하면 `icon.gd`의 `paint()`에 같은 id로 아이콘을 그려 넣는다(없으면 동그라미)

## 지형물 파괴

- 폭발(지원요청 폭격·수류탄·작렬탄·전차 포탄·자주포)에 걸린 엄폐물은 내구도가 깎이고 0이 되면 부서진다. 총알로는 깎이지 않는다
- 내구도: 나무 80, 모래주머니 150, 차량 160, 컨테이너 450, 바위 700, 건물 800. 적 포탄은 피해 x8로 계산한다
- 부서지면 충돌·시야에서 빠진다. 건물만 낮은 잔해(지나갈 수 없음, 탄환·시야는 통함)로 남고, 차량은 0.18초 뒤 유폭한다(반경 58)

## 상점 (해금 트리)

- 지원요청: 공중 타격 / 포격·미사일 / 거점 화력 / 정보·전자전 / 보급·방호 다섯 계열. 계열 안에서는 왼쪽 것을 가져야 오른쪽 것을 살 수 있다(`Data.BRANCHES`, `Data.req_of`)
- 무기: 계열마다 1 → 2 → 3등급 순서로 산다(`Data.wreq_of`). 구매 창은 지금 장착한 무기 대비 화력·탄창·재장전·사거리 차이를 %로 보여 준다

## 좌표

논리는 프로토타입과 같은 2D "게임 단위"(맵 3000 x 3000)로 돌고, 그릴 때만 3D로 옮긴다.

- 위치: `(x, y)` → `Vector3(x * 0.06, 높이, y * 0.06)` (`Game.p3`)
- 각도: 게임 각도 `a` → `rotation.y = -a`. 모든 모델은 +X를 바라보게 만든다
- 엄폐물 높이는 `h * 0.09` m

## 지원요청 연출

- 폭격류(정밀 공습·기총소사·네이팜·융단 폭격)는 실제 폭발 지점마다 실제 피해 반경 원을 그린다(테두리 고정, 안쪽이 시간에 따라 차오름)
- 전투기(융단 폭격은 폭격기)가 공격선 위를 지나가며 폭탄을 떨어뜨리고, 땅에 기체 모양 그림자가 지나간다. 제트 굉음은 `flyby()`에서 합성

## 원격 지원 (나중에 추가한 5종)

- 저격 지원: 15초 동안 1.1초마다 반경 560 안에서 위협이 가장 큰 적 하나를 쏜다(증원 요청 중 > 교전 중 > 소총병 > 방패병 > 돌격병). 장갑 차량에는 큰 피해만 준다
- 함포 사격: 3초 예고 뒤 0.9초 간격으로 반경 150짜리 포탄 3발. 아군 피해 있음
- 연막 차장: 12초간 반경 150 연막. 플레이어나 적이 그 안에 있으면 적은 플레이어를 보지 못한다
- 전자전: 20초간 무전병이 증원을 부르지 못하고(요청 중이면 끊김) 드론·전차·자주포가 멈춘다
- 위성 정찰: 30초간 미니맵에 모든 적 표시
- 저격·전자전·위성·방호 장막은 방공망에 요격되지 않는다. 진행 중인 저격·전자전·위성은 미니맵 아래에 남은 시간이 뜬다

## 거치 기관총 · 공격헬기 · 아군 기갑

- 거치 기관총(지원요청): 진지를 투하하고, 반경 30 안에 서 있는 동안 주무기 대신 중기관총(연사 15, 관통 2, 사거리 380, 탄약 무제한)을 쏜다. 25초 뒤 사라진다. 요청 드론은 자동 호출하지 않는다
- 공격헬기(지원요청 `apache`): 25초 동안 플레이어 주위 130 거리 상공을 돌며 기관포를 쏘고 4초마다 로켓 4발을 쏜다. 떠 있는 동안 다시 부르면 체공 시간만 채운다. 방공망이 살아 있으면 요격되거나 격추된다
- 경전차 지원(`ltank`, 30초) · 전차 지원(`tank`, 35초): 투하된 뒤 플레이어를 따라다닌다. 경전차는 기관포 3점사(작렬탄), 전차는 2.6초마다 주포(기갑 우선, 없으면 적 밀집 지점)와 동축 기관총. 적은 아군 기갑을 노리지 않고, 플레이어 길도 막지 않는다

## 진급 보급: 부대원 · 드론 편대

- 부대원 합류(Lv1~4): 소총수 → 지원병(경기관총) → 공병 → 의무병(초당 1.5 회복). 플레이어 뒤 대형으로 따라오고 26 안으로 오면 밀려난다. 은신 중에는 플레이어 사거리 밖의 적에게 먼저 쏘지 않는다
- 부대원(체력 70, 특수부대 120)과 드론(체력 30)은 적 탄환·포탄에 맞아 쓰러진다. 부대원 20초(특수부대 12초), 드론 12초 뒤 복귀한다. 다치면 머리 위에 파란 체력 막대가 뜬다
- 포위 돌파: 300 안의 교전 중인 적이 8명 이상이고 8방향 중 6방향 이상을 메우면, 가장 얇은 방향(±1.1 rad)의 적에게 화력을 모으고(연사 약 1.8배) 그 방향을 초록 부채꼴로 표시한다
- 공병: 단말기·통신탑 구역에 들어가면 6초 뒤 부호를 대신 넣는다(특수부대 분대는 3초). 탈출 SOS는 대신 치지 않는다
- 진화 특수부대 분대(부대원 Lv3 + 방탄판 Lv2): 화력 +60%, 관통 +1, 의무병 회복 2.5
- 드론 편대(Lv1~5): 사격(24발 뒤 1.6초 재장전) → 자폭(9초마다 출격) → 화염방사 → 전기(연쇄 4명, 잠깐 멈춤) → 방어(105 안으로 날아오는 적 탄환·포탄 요격)
- 진화 군집 드론(드론 편대 Lv3 + 속사 장치 Lv3): 자폭 드론 4기씩, 사격 드론 3기

## 요청 드론 (진화)

- 조건: 통신 증폭기 Lv3 + 대형 탄두 Lv2 (무기 무관)
- 플레이어 어깨 뒤를 따라다니며 장착한 지원요청을 0.8초마다 판단해 자동 호출한다. 재사용 대기는 플레이어와 따로 돈다(HUD 카드 아래 하늘색 막대)
- 공격형은 교전 중이고 표적이 있을 때만, 보급은 체력 50% 미만, 의무 지원은 교전 중 60% 미만, 방호 장막은 교전 중 35% 미만일 때. 초대형 폭탄은 자동 호출하지 않는다
- 방공포 교란 구역 안에서는 드론도 호출하지 못한다

## 작전 지도

- 지구본은 고정 시드(`WORLD_SEED`)라 매번 같은 세계. 위도로 바이옴이 정해진다: 적도 사막, 중위도 산림, 고위도 설원
- 스테이지 10곳이 `Save.d.missions`에 순서대로 저장되고, `Save.d.stage`가 열린 스테이지 수다. 성공하면 다음 스테이지가 열린다(잠긴 곳은 지구본에서 흐리게 보이고 고를 수 없다)
- 스테이지 1 → 10: 적 체력 x0.85 → x1.5, 받는 피해 x1.0 → x1.3, 진지 경비 +0 → +7명, 순찰조 8 → 22개, 전초기지 3 → 9곳, 증원 요청 3.4초 → 2.0초, 증원 기본 병력 16 → 32명, 보상 x1.0 → x3.25. 스테이지 5부터 파괴 목표마다 전차 1대 추가, 7부터 단말기·통신탑에도 전차, 8부터 자주포 1대 추가. 표시용 위험도는 1~2 정찰, 3~6 교전, 7~10 격전

## 보스 (스테이지 5 · 8 · 10)

주 임무가 단말기 해킹 대신 보스 격파로 바뀐다. 보스는 `en`에 들어 있는 적이고(`Game.boss`), 보스 지점 목표(`type = "boss"`)가 그 적을 따라다닌다. 가까이 가거나(480), 맞거나, 증원이 한 번이라도 오면 깨어난다. 넉백·소용돌이에 밀리지 않고 전자전에는 3초만 멈춘다. 움직이는 보스는 엄폐물을 밟아 부순다.

| 스테이지 | 보스 | 체력 | 행동 |
| --- | --- | --- | --- |
| 5 | 다포탑 중전차 「코뿔소」 | 4500 | 주포 직사(4.2초) + 부포탑 2개의 기관포 3점사. 체력 66%·33%에서 부포탑이 하나씩 떨어진다 |
| 8 | 열차포 「천둥」 | 7000 | 제자리. 맵 어디든 9초마다 반경 120 포탄(3.2초 예고). 450 안에서는 기관포 |
| 10 | 이동 지휘 요새 「성채」 | 9000 | 주포 + 기관포 + 7초마다 미사일 4발. 체력 75%까지는 방공 포탑이 살아 있어 지원요청이 요격당한다. 50%에서 증원 호출, 40%부터 미사일 6발 |

체력은 스테이지 배율이 더 곱해진다. 총알은 장갑 때문에 50~60%만 들어간다.

## 게임 규칙 요약

- 주 임무: 단말기 2곳 해킹 → 탈출 SOS(`...---...`) → 30초 버티기 → 헬기 탑승
- 단말기 하나는 부호 3번으로 해킹한다. 넣을 때마다 5초 뒤 새 부호가 나오고(그동안은 입력할 것이 없다), 첫 입력 직후 화면 밖(거리 520~610)에서 정찰대 4~7명이 수색 상태로 단말기 쪽에 오고, 이후 해킹이 끝날 때까지 정찰대가 6~9초마다 계속 온다. 두 번째 입력 직후에는 8초간 사이렌이 울리고 증원 요청 대기가 0으로 풀리며 정찰대 간격이 3.5~5.5초로 줄어든다. 무조건 오는 대규모 증원은 없고, 정찰대가 플레이어를 발견해 무전을 쳐야 증원이 온다
- 보조 임무: 통신탑(구역·적 위치 공개) / 적 부대(증원 병력 절반) / 방공포(반경 안 지원요청 불가, 파괴 시 재사용 대기 25% 감소) / 미니맵 교란기(살아 있는 동안 맵 어디서든 미니맵 먹통이고, 지점을 찍는 지원요청은 좌표가 120~320 빗나가고 방향도 틀어진다. 즉시 발동형은 영향 없음. 파괴 시 주변 560 안의 적이 미니맵에 표시) / 군수공장(가동 중에는 증원마다 전차 1대 추가, 파괴 시 증원에서 전차·드론 제외)
- 통신탑은 구역 안에서 모스 부호로 해킹해야 점령이 시작된다
- 방공망: 스테이지 3부터는 방공포가 살아 있으면 맵 어디서 불러도 지원요청이 요격당한다(재사용 대기는 그대로 소모, 방호 장막 제외). 첫 요격 때 방공포 위치가 지도에 드러난다. 스테이지 1~2는 방공포 반경 430 안에서만 "교란"으로 막힌다
- 전차는 붉은 조준선을 0.7초 겨눈 뒤 포탄을 직사한다(맞거나 벽에 닿으면 폭발). 자주포는 멀리서 곡사하며 떨어질 자리를 1.5초 전에 표시한다. 방공포·교란기는 자주포가, 부대·군수공장은 전차가 지킨다
- 기갑 4종: 경전차(빠르고 얇음, 1.7초마다 기관포 3점사. 조준선 없음) / 전차(3.4초마다 주포 직사) / 자주포(곡사, 1.5초 예고. 포탄이 연기 꼬리를 끌며 포물선으로 날아오는 것이 보인다) / 이동식 미사일 발사대(거리 900에서 4발 연사, 2초 예고, 가까이 오면 물러남)
- 증원 기갑 편성(증원을 처음 불렀을 때 → 세 번 넘게 불렀을 때): 스테이지 1~2 없음 → 경전차, 3~4 경전차 → 경전차+전차+자주포, 5~6 경전차+전차 → +자주포+미사일, 7~8 경전차+전차+자주포 → 경전차 2+전차+자주포+미사일, 9~10 경전차 2+전차+자주포+미사일
- 길리 저격수: 목표에서 230~380 떨어진 곳에 엎드려 있다. 지면 색 덤불 모양이고 외곽선·그림자·시야 표시가 없다. 시야(430)에 플레이어가 들어오면 붉은 조준선을 1.5초 겨눈 뒤 빠른 탄 한 발(피해 28)을 쏘고 3.6초 쉰다. 자동 조준·포탑·드론은 조준 중(반짝임)·사격 뒤 2.5초·거리 90 안에서만 저격수를 잡는다. 연막 안에서는 못 본다. 위성 정찰이나 통신탑 점령으로 지도에서 위치를 볼 수 있다
- 소총병은 사격 거리(185)에 들면 멈춰 서서 쏘고, 250 넘게 멀어지거나 시야를 잃어야 다시 쫓는다
- 적은 경비병·전초기지·순찰조로 배치된다. 시야(부채꼴)·소음으로 발각되고, 교전에 들어가면 무전병이 2.8초 동안 증원을 부른다(처치하면 차단)
- 플레이어를 보고 있는 적이 하나라도 있으면 0.5초마다 위치가 퍼진다: 380 안의 적은 바로 교전, 800 안의 적은 그 자리로 수색하러 온다
- 탈출 SOS를 치면 신호탄이 올라가고 맵 전체의 적이 교전 상태로 몰려온다
- 30초 뒤 헬기가 온다. 착륙장 반경 270 안의 적은 미니건이 쏘고(0.05초마다 55 피해), 반경 170 안이 0.6초 비면 착륙한다. 착륙 뒤 플레이어가 들어서면 2초 이탈 연출 뒤 임무 성공. 헬기가 온 뒤로는 추가 스폰이 멈춘다
- 플레이어는 이동 방향을 바라보고, 사거리 안 가장 가까운 적을 자동 조준해 쏜다
- 통신탑 점령을 시작하면 은신 여부와 상관없이 탑 근처에 있는 동안 7초마다 적 증원이 온다(적 부대 파괴 시 절반). 점령 게이지는 구역을 벗어나도 줄지 않는다
- 발각 후 무전 증원은 22명+(증원 횟수x8), 최대 60명이 3파로, 다섯 방향에서 포위하듯 몰려온다. 순찰조는 16개조(교전 기준) 3~5명
- 무기 진화 순간은 짧은 알림뿐이고, 진화한 무기 자체가 세다: 화력 +35%, 색 궤적·발광 총열, 처치한 적이 터지며 주변에 피해. 스마트 소총은 연사 +30%에 4번 도탄, 용의 숨결은 관통 +2에 불붙은 적이 죽으며 폭발, 미니건은 연사 +90%에 다섯 발마다 작렬탄, 플라즈마 레일은 명중마다 큰 폭발
- 부호가 겹치면(짧은 부호가 긴 부호의 앞부분) 0.6초 기다렸다가 짧은 쪽을 발동한다
